## D-10 密钥与备份：**一律不加密**（终局决定，不再重议）
主人两次明确否决，第二次给出理由：**"我自己用，麻烦死了；忘了加密方式和密码我怎么办。"**

规则：
1. **不引入 Android Keystore，不做口令派生，导出/备份包全部明文**。备份文件顶多进 zip 容器（**只是打包，不是加密**）。
2. 备份只做两件事：① **完整性校验**（每个文件 sha256，防传坏/截断——这跟加密无关，不要求任何口令）② **导入前预检报告**：逐项列出「将覆盖 / 缺失 / 多余 / 版本不匹配」，让主人确认后才落库。
3. 需要"给别人看之前抹掉密钥"这种场景，用**导出时勾选"不包含密钥"**解决，**不用加密解决**。
4. 遗留 `enc:v1:` 密文（Agora 存的）**在 Hualuo 里注定解不开**（Keystore 密钥不可导出，换设备即失效）→ 导入时**逐项点名报错**："第 N 项 xxx 的密钥是旧版加密，本机解不开，请重新填一次"。**禁止静默置空串。**
5. 废除 `SecretCrypto` 的两个坏行为：`encrypt` 失败 fail-open（我们根本没有 encrypt 这一步了）、`decrypt` 异常返回 `""`（改为显式报错）。
6. 明文的风险边界照实写进隐私说明：密钥放 app 私有目录，非 root 手机上其他 app 读不到；**root 机 / adb backup / 你把备份文件发到群里** = 明文可见。这个取舍是主人主动选的，不再拿它当理由劝加密。

> ⚠️ **`UPSTREAM.md` §坑4 里"密钥禁止明文回退、加密失败就拒绝保存并报错（R7）"这句作废**，以本 D-10 为准。
